# MAXIMA ERP — Frontend Interface

![React](https://img.shields.io/badge/React-18-61DAFB?style=flat-square&logo=react) ![Vite](https://img.shields.io/badge/Vite-5-646CFF?style=flat-square&logo=vite) ![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-3-06B6D4?style=flat-square&logo=tailwindcss) ![pnpm](https://img.shields.io/badge/pnpm-9-F69220?style=flat-square&logo=pnpm) ![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)

An Executive B2B ERP Dashboard interface designed for managing sales orders, customer databases, product catalogs, and operational reports with dynamic sales status workflows. Built with performance, modular architecture, and clean UI standards in mind.

---

## 📸 Overview & Features

- **Executive Dashboard:** Real-time KPI summary cards, revenue trend charts, order status distribution breakdown, and recent transaction feeds.
- **Sales Order Workspace:** Interactive slide-over detail drawer featuring state-driven workflow actions (`Needs DO` -> `Needs Invoice` -> `Closed`).
- **Customer Master Data:** Filterable B2B client management directory with quick-action operations.
- **Product Catalog:** Inventory management table complete with unit pricing and stock indicators.
- **Executive Reports:** Instant PDF invoice and slip generation utility via direct browser print engine.

---

## 🛠️ Tech Stack & Architecture

- **Core Framework:** [React.js](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Package Manager:** [pnpm](https://pnpm.io/)
- **Architecture Standard:** Single-Responsibility Components, Pure Utility Formatters, and Deterministic State Hooks.

## 🚀 Getting Started

Follow these step-by-step instructions to get the project running locally.

### Prerequisites

Ensure you have Node.js (v18 or higher) and `pnpm` installed on your machine.

- Verify Node version:
  ```bash
  node -v
  ```
- Install `pnpm` globally (if not already installed):
  ```bash
  npm install -g pnpm
  ```

### Installation & Execution

1. **Clone the Repository**

   ```bash
   git clone [https://github.com/sholihdinrizky/MAXIMA-ERP-FE.git](https://github.com/sholihdinrizky/MAXIMA-ERP-FE.git)
   cd MAXIMA-ERP-FE
   ```

2. **Install Dependencies**

   ```bash
   pnpm install
   ```

3. **Start Development Server**

   ```bash
   pnpm dev
   ```

4. **Access the Application**
   Open your web browser and navigate to `http://localhost:5173`.
